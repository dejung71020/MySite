 Aespa 팬 웹사이트 

소개

이 프로젝트는 K-Pop 걸그룹 Aespa(에스파)의 팬들을 위해 제작된 단일 페이지 웹사이트입니다. Aespa의 강렬하고 미래지향적인 콘셉트에 맞춰 사이버펑크 스타일의 다크 테마를 적용했습니다.

순수 HTML, CSS, JavaScript로 구현되었으며, 반응형 웹사이트입니다.

주요 특징

1. 사이버펑크 디자인 및 테마

색상 팔레트: 주요 색상으로 일렉트릭 마젠타 (#FF3BFF)와 사이버 시안 (#03E8F9)을 사용하여 어두운 배경 (#10101A) 위에서 네온 효과를 극대화했습니다.

부드러운 스크롤: 섹션 간 이동 시 부드러운 스크롤(Smooth Scroll) 기능을 적용하여 사용자 경험을 향상시켰습니다.


2. 동적 '수상' 기록 필터링 기능 (깃허브사이트에서 제공하는 페이지에서는 사용불가)

#achievements 섹션에서는 Aespa가 받은 음악 방송 트로피 기록을 기준으로 콘텐츠를 동적으로 필터링합니다.

버튼 기반 필터링: 사용자가 '1관왕', '2관왕', 'ALL' 등의 버튼을 클릭하면, 해당 data-category 속성과 일치하는 수상 항목만 화면에 표시됩니다.

카운트 뱃지: 각 필터 버튼에는 해당 카테고리에 속하는 항목의 개수가 실시간으로 표시됩니다.

레이아웃 조정: 필터링 결과가 **단일 항목(1개)**일 경우, 그리드 레이아웃이 중앙 정렬된 단일 열로 자동 변경되어 시각적 안정감을 제공합니다.

3. 구성 섹션

섹션 ID

내용

#home

환영 인사 및 팬 아바타

#about

멤버별 이름, 생년월일 및 솔로곡 정보

#aespa_concept

그룹 콘셉트, '쇠맛' 특징 설명, 능력치 바 그래프, 주요 노래 및 로어 정보

#achievements

음악 방송 트로피 수상 기록 및 동적 필터링 기능

#sayings

멤버들의 명언 및 멘트를 말풍선 형태로 표시

#contact

연락처 및 소셜 미디어 링크 (푸터)

.arrow-up

클릭 시 화면 최상단으로 이동하는 '위로 가기' 버튼

기술 스택

HTML5: 웹사이트 구조 및 콘텐츠

CSS3: 스타일링 및 완벽한 반응형 디자인 (Media Queries 사용)

JavaScript (Vanilla JS): 동적 필터링, 메뉴 토글, 스크롤 인터랙션 구현

실행 방법

이 프로젝트는 단일 HTML 파일로 구성되어 있으므로, 파일을 다운로드하여 웹 브라우저에서 직접 열어야 바로 실행할 수 있습니다.
